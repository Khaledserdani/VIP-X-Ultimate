# VIP X — تطبيق مشاهدة شخصي

VIP X تطبيق Android شخصي مستقل. التطبيقات الأصلية تبقى مثبتة وغير معدّلة.

## ما هو موجود في فرع التطوير
- مشغّل وسائط مستقل يستقبل رابط بث مباشر HTTPS يملكه المستخدم أو يملك تصريح مشاهدته.
- مشغّل مبني على AndroidX Media3 مع خدمة جلسة وسائط لتوفير التشغيل في الخلفية وإشعار التحكم.
- وحدات HLS وDASH للبث المتوافق مع ExoPlayer.
- نافذة فيديو عائمة Picture-in-Picture على إصدارات Android الداعمة لها.
- التحكم بسطوع شاشة النظام بعد منح إذن Android.
- مختبر محلي لاختبار AES-GCM على بيانات تجريبية يملك التطبيق مفتاحها.

## الحدود التقنية
المشغّل لا يستخرج روابط البث من تطبيقات أخرى، ولا يعترض جلساتها أو مفاتيحها، ولا يتجاوز DRM. المحتوى المحمي يحتاج إعداد ترخيص صالحاً من مزوّد الخدمة، وهذا الإصدار لا يوفّر واجهة إعداد DRM. كما أن رابط صفحة ويب عادية ليس بالضرورة رابط وسائط مباشر صالحاً للمشغّل.

التشغيل في الخلفية يخص المحتوى الذي بدأ تشغيله داخل مشغّل VIP X نفسه؛ ولا يعني الاستحواذ على بث تطبيق آخر أو إبقاء فيديوه يعمل قسراً. النافذة العائمة تعتمد على دعم Android وسياسة الجهاز.

## الخصوصية والترخيص
للاستخدام الشخصي الخاص فقط. لا توجد خدمة مدفوعة أو API مدفوعة أو خادم تفعيل. هذا النص يوضح غرض الاستخدام ولا يفرض قفلاً تقنياً على جهاز واحد بعد.

## بيئة البناء
- Android Gradle Plugin: 9.3.1
- Gradle Wrapper: 9.6.1 (with the official distribution SHA-256 pinned in gradle-wrapper.properties)
- Kotlin / Compose Compiler: 2.3.21
- Java toolchain: 17 أو أحدث
- Android SDK Platform: API 36 (required by AndroidX Media3 1.11.1)

ملفات Gradle Wrapper الرسمية أصبحت ضمن المستودع، ويمكن تشغيل `./gradlew assembleDebug` من بيئة تطوير Android متوافقة. أول بناء يحتاج تنزيل Gradle وAndroid SDK والحزم من مستودعاتها، لذلك يحتاج اتصال إنترنت أثناء الإعداد.

## التحقق
المصدر محفوظ في فرع التطوير. لا تعتبر النسخة جاهزة للتثبيت حتى يتم بناء APK بنجاح، ثم تثبيته وتجربة بث HTTPS فعلي والتحقق من الخلفية وPiP على جهاز Android حقيقي. لا يوجد في هذا المستودع ادعاء بأن هذه الاختبارات قد اجتازت بعد.
