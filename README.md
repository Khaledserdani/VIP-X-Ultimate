# VIP X — Live Grid

VIP X is a standalone Android companion focused on multi-preview live-broadcast browsing for Tango.

## Current app scope
- Dedicated Arabic RTL Live Grid interface.
- Tango is the only target app.
- 2/3-column layout, 2/4/6 preview-slot setting, and data-saver limit.
- One-tap launch of the original Tango app.
- Read-only Android diagnostics: network type/validation, estimated link bandwidth, metered connection, available RAM, and thermal status.
- No replacement, modification, repackaging, or injection into Tango.
- No account automation, paid-feature unlocking, private traffic extraction, or protected-stream bypass.

## Important status
No authorized live-preview source is connected yet. Preview slots intentionally show unavailable states; they are not fake streams or screenshots. Multi-live playback is not implemented.

Tango's official blog confirms a public API aimed at agencies and power users, describing creator-approved chat, media-vault, creator-streaming and webhook capabilities. The public announcement does not specify viewer-facing multi-room preview playback. The full linked developer documentation still needs a reliable review before any integration decision.

## Reuse policy
Only general engineering lessons from the earlier VIP X codebase may be reused. Previous APK-analysis, AI assistant, cloud gateway, accessibility overlay, and agent features are excluded from this product.

## Build policy
No cloud builds, CI workflows, release uploads, or APK distribution are configured in this branch. Personal use only.
