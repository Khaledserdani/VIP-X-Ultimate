# VIP X Ultimate

تطبيق Android أصلي باستخدام Kotlin وJetpack Compose، بواجهة عربية RTL ومعرّف الحزمة `com.vipx.ultimate`.

## مبدأ المنتج
VIP X Ultimate ليس اسماً تسويقياً ولا مجرد مدير تطبيقات. هو مركز أدوات ذكي يمنح المستخدم قدرات عملية متقدمة لإدارة التطبيقات، تحليلها، تجهيز المشاريع، ومساعدته أثناء الاستخدام ضمن صلاحيات Android. لا نعتمد تقسيم الشاشة إلى قسمين؛ هذه الفكرة مستبعدة نهائياً.

## إصدار إعادة البناء 2.0.0 — ما هو موجود في الكود
- واجهة رئيسية واحدة عربية RTL.
- تحميل قائمة التطبيقات في الخلفية حتى لا تتجمد الواجهة عند التشغيل.
- بحث بالاسم أو اسم الحزمة.
- عرض معلومات التطبيق: الحزمة، الإصدار، الحجم، تواريخ التثبيت والتحديث، والصلاحيات المعلنة.
- فتح التطبيق وإعداداته.
- حساب SHA-256 عند الطلب فقط.
- تصدير نسخة ZIP تشمل APK الأساسي وكل ملفات split.
- مدخل منفصل للمساعد السحابي؛ تشغيل الذكاء الفعلي مشروط بإعداد الخادم ومفاتيحه.

## ميزات VIP الجوهرية — متطلبات مثبتة وليست ادعاء إنجاز
### 1. مختبر التطبيقات
- [ ] تحليل أذونات التطبيق وتصنيفها إلى عادية وحساسة وخطيرة مع شرح سبب التصنيف، دون الادعاء أن الإذن وحده يثبت وجود برمجية خبيثة.
- [ ] تحليل بيانات APK المتاحة: التوقيع وبصمات الملفات والحجم والمكونات المعلنة ومقارنة الإصدارات عند توفرها.
- [ ] تقرير مفهوم عن مؤشرات السلامة والمخاطر مع الأدلة ودرجة ثقة؛ لا تسمية التطبيق خبيثاً دون فحص موثوق.
- [ ] كشف التطبيقات الكبيرة والمتكررة والملفات الاحتياطية، مع اقتراحات تنظيف لا تنفذ إلا بموافقة المستخدم.

### 2. مركز تحكم ذكي
- [ ] لوحة موحدة للتطبيقات والألعاب والأدوات والمهام، بواجهة كاملة واحدة لا تقسيم نصفين.
- [ ] اختصارات قابلة للتخصيص وتشغيل إجراءات مسموحة للتطبيق المحدد.
- [ ] سجل نشاط ومهام يوضح ما تم وما فشل وسبب الفشل.

### 3. أدوات VIP أثناء الاستخدام
- [ ] أدوات عائمة اختيارية وسريعة بعد إذن الظهور فوق التطبيقات، مع زر إيقاف واضح.
- [ ] نوافذ PiP فقط للسيناريوهات التي يدعمها Android والتطبيق المقصود.
- [ ] أدوات مساعدة للألعاب والتطبيقات مثل الاختصارات والمؤقت ومراقبة موارد الجهاز وملاحظات الجلسة؛ دون حقن أو تعديل ذاكرة أو تجاوز حماية اللعبة.

### 4. مهندس الذكاء الاصطناعي
- [ ] مساعد يفهم طلب المستخدم وسياق التطبيق أو المشروع الذي اختاره.
- [ ] تحليل ملفات المشروع واقتراح تعديلات فعلية مع عرض الفروقات قبل التطبيق.
- [ ] تنفيذ التعديل بعد موافقة المستخدم، ثم تشغيل الاختبارات وإظهار النتائج والسجلات.
- [ ] عدم إعلان نجاح أو جاهزية قبل نجاح البناء والاختبارات فعلياً.

### 5. مختبر البناء والتكامل
- [ ] فتح مشاريع Android المدعومة وتحليل بنيتها وملفاتها.
- [ ] بناء APK وتشغيل اختبارات المشروع وإظهار الأخطاء مع مواضعها.
- [ ] تكامل GitHub لمراجعة المستودعات والفروع وطلبات الدمج ونتائج Actions بصلاحيات يوافق عليها المستخدم.
- [ ] تكامل المساعد السحابي عبر HTTPS مع حفظ الأسرار خارج APK والمستودع.

## ضوابط التنفيذ
- كل بند أعلاه غير مؤشّر عليه [x] هو مهمة مستقبلية، وليس ميزة مكتملة.
- لا ميزات VIP وهمية، ولا فتح خدمات مدفوعة أو ميزات محمية خادمياً، ولا تجاوز DRM أو أنظمة الدفع والاشتراكات.
- لا قراءة لبيانات التطبيقات الخاصة أو تعديل تطبيقات الآخرين دون إذن.
- أقل صلاحيات Android لازمة، وشرح واضح قبل طلبها.
- لا تنفيذ تغييرات أو حذف ملفات أو تثبيت حزم دون موافقة المستخدم حيث يتطلب النظام ذلك.
- لا تعديل للفرع main أو دمج طلب السحب دون موافقة صريحة.
