# VIP X Ultimate 2.6.0

**VIP X** تطبيق Android عربي مستقل لمشاهدة الوسائط التي يختارها المستخدم وإدارتها محلياً. لا يحتاج Root، ولا يغيّر التطبيقات الأخرى أو يحقن فيها.

## الوظائف الموجودة في مصدر فرع التطوير

- **مكتبة الوسائط:** اختيار الصور والفيديوهات من منتقي Android الرسمي، ومعاينتها داخل مساحة التطبيق.
- **تشفير VIPXENC:** تشفير وفك تشفير ملفات الصور والفيديو التي أنشأها المستخدم داخل VIP X، بكلمة مرور يحددها المستخدم.
- **مشغّل مستقل:** تشغيل روابط HTTPS المباشرة المتوافقة مع Media3، بما فيها HLS وDASH، مع خدمة تشغيل في الخلفية وإشعار تحكم.
- **شبكة البث المباشر 2×2:** تصميم لتشغيل حتى أربعة مصادر يضيفها المستخدم بنفسه، مع اختيار مصدر صوت واحد وإمكانية إعادة المحاولة يدوياً.
- **النوافذ العائمة:** نافذة لمعاينات البث المسجلة في VIP X، ونافذة منفصلة لوسيط محلي يختاره المستخدم.
- **صورة داخل صورة (PiP):** للمشغّل الكامل على إصدارات Android الداعمة.
- **أدوات النظام:** التحكم في سطوع الشاشة بعد منح إذن Android المطلوب.

هذه قائمة بوظائف المصدر، وليست ادعاءً بأن كل وظيفة اجتازت اختباراً على هاتف فعلي.

## الخصوصية وحدود الاستخدام

- كل تشغيل أو استيراد يبدأ باختيار المستخدم أو إدخال رابط يملك حق استخدامه.
- مشاركة ملف من تطبيق آخر تعتمد على إذن Android المؤقت `content://`؛ لا يفحص VIP X مجلدات التطبيقات الخاصة أو ذاكرة الهاتف.
- لا يستخرج روابط أو رموز جلسات أو مفاتيح من تطبيقات أخرى.
- لا يتجاوز DRM أو Widevine. المحتوى المحمي يحتاج رابط ترخيص وبيانات اعتماد صالحة من مزوّد الخدمة.
- VIPXENC صيغة خاصة بملفات VIP X التي يملك المستخدم كلمة مرورها؛ ليست أداة لفك تشفير ملفات أو بثوث عشوائية.
- لا توجد خدمة سحابية إلزامية أو API مدفوعة أو اشتراك أو خادم تفعيل.
- لا يلزم VPN؛ يستخدم التطبيق اتصال الإنترنت العادي عند تشغيل مصادر HTTPS.

لبناء نسخة تجريبية محلياً من بيئة Android متوافقة:

```bash
./gradlew --no-daemon testDebugUnitTest
./gradlew --no-daemon assembleDebug
```

الناتج المتوقع عند نجاح البناء:

```
app/build/outputs/apk/debug/app-debug.apk
```

يحتاج أول إعداد إلى اتصال لتنزيل Gradle وAndroid SDK والاعتماديات. لم يُسجّل في هذا المستودع حتى الآن إثبات بناء محلي ناجح أو اختبار قبول على هاتف فعلي لهذه النسخة. لا تعتبر APK جاهزاً للاستخدام قبل إتمام التحقق المحلي واختبارات الجهاز.

## ما يجب اختباره قبل اعتماد الإصدار

1. بناء Debug محلياً وتشغيل اختبارات الوحدة.
2. تثبيت التطبيق على جهاز Android مستهدف وفحص الأذونات.
3. اختبار صور وفيديوهات محلية، وتشفير VIPXENC وفكّه مع كلمة مرور صحيحة وخاطئة وملف تالف.
4. اختبار رابط HLS ورابط DASH مصرح بهما، ثم اختبار بثين وأربعة بثوث.
5. اختبار النافذة العائمة وPiP، والتنقل للخلفية والعودة، وإيقاف كل البثوث.
6. قياس الذاكرة والبطارية والحرارة والشبكة على الهاتف؛ حد أربعة بثوث سقف برمجي وليس ضماناً لقدرة كل جهاز على فك أربعة تدفقات.

## حدود المنتج

VIP X مشغّل وسائط مستقل ومكتبة شخصية، وليس أداة لالتقاط البث من تطبيقات أخرى أو تجاوز اشتراكاتها أو أنظمة حمايتها. لا يُعلن دعم بث محمي إلا بعد نجاح اختبار فعلي بمصدر وترخيص صادرين من مزوّد الخدمة.
